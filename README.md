# Radium
A Geometry Dash Mod Menu Built On Geode.
## Features
- TPS Bypass
  - 60-10000 TPS
- Noclip
- Macro Tool (Radium Replay)
- Unlock Icons
- Unlock Main Levels
-  Speedhack
## Platforms
### Desktop Platforms
- Windows
- MacOS
### Mobile Platforms
- Android64
## How To Open The Menu
**On Desktop Platforms:**
Press the TAB key on your Keyboard.
**On Mobile Platforms:**
Press The Movable Button.
## Building Locally
Set The `GEODE_SDK` Environment variable, then run `geode build`.
