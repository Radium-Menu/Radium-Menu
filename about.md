# Radium

A Geometry Dash mod menu.

Open the menu with **Tab** on desktop, or the floating **Ra** button on Android and iOS.

## Features

- **TPS bypass** from 60 to 10000
- **Speedhack** from 0.01x to 10x
- **Noclip** with a blocked-deaths counter
- **Unlock all icons and colors**
- **Main level bypass** for locked main levels
- **Vbot support** for macro recording, macro replay and the renderer

## Platforms

Windows, macOS, iOS and Android 64-bit. Android 32-bit is not supported.

## Vbot

Install [Vbot](https://github.com/Vbot-Macro/Vbot) to use the Vbot tab.
